## MusicDB Database

Some of the SQL examples use the included SQLite database:

```text
data/MusicDB.db
```

The database contains related data such as customers, invoices, invoice items, tracks, albums, artists, genres and media types.

### How to Test the Queries

1. Download or clone this repository.
2. Open **DB Browser for SQLite**.
3. Open `data/MusicDB.db`.
4. Go to **Execute SQL**.
5. Open or copy one of the `.sql` files from the `sql` folder.
6. Run the query to view the results.

> The `.sql` files are normal SQL source files. Using `.sql` instead of `.txt` makes the repository clearer, gives SQL syntax highlighting on GitHub, and allows SQL tools such as DB Browser for SQLite to open the files directly.
